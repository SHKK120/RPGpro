# 시작

## 문서의 역할

모든 작업을 시작할 때 필요한 최소 문서로 안내하는 문서 라우터다.

## 이 문서가 소유하는 정보

- 프로젝트 환경 요약
- 공통 작업 용어
- 작업 종류별 문서 라우팅
- 문서와 게임 데이터의 정본 원칙

## 이 문서가 소유하지 않는 정보

- 개별 게임 시스템의 상세 규칙
- 실제 수치와 콘텐츠 값
- 구현 코드와 리소스

## 환경 요약

- 프로젝트 루트와 도구 경로의 정본: `01_환경복구.md`
- 엔진: Godot 4 계열. 정확한 버전의 정본은 `01_환경복구.md`
- 현재 조각과 다음 행동의 정본: `40_구현순서.md`

## 용어

개발 작업 단위는 Godot의 Scene과 혼동하지 않도록 **조각(Slice)** 이라고 부른다.

## 정본 원칙

- 문서는 **왜 그렇게 정했는지**를 기록한다.
- 실제 수치와 콘텐츠 값은 나중에 게임 데이터가 정본이 된다.
- 같은 사실을 여러 문서에 중복해서 확정하지 않는다.

## 문서별 정본 소유

- `01_환경복구.md`: 환경 경로, 도구 버전, 복구 절차
- `10_정체성.md`~`15_전투.md`: 경험, 플레이 규칙, 시각 원칙
- `30_데이터구조.md`~`35_멀티경계.md`: 데이터, 저장, 권한의 의미와 경계. 실제 수치는 게임 데이터가 생긴 뒤 그쪽이 정본이다.
- `40_구현순서.md`: 현재 작업 상태와 다음 행동. 이 문서에 같은 상태를 별도로 복제하지 않는다.
- `50_닫을것.md`: 미정 질문, 제안, 결정 이력. 확정된 규칙 본문을 통째로 중복 보관하지 않는다.
- `60_나중에.md`: 보류 아이디어와 다시 여는 조건
- `지시장부.md`: 실제 지시와 실제 변경 이력
- `기록함/`: 예전 지시, 보고, 이미지. 현재 규칙을 결정하는 자동 입력이 아니다.
