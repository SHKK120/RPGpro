# 핵심 플레이 루프 규칙

## 문서의 역할

플레이어가 반복해서 수행하는 핵심 플레이 흐름을 정의한다.

## 이 문서가 소유하는 정보

- 핵심 행동의 반복 구조
- 행동, 보상, 성장의 연결 관계
- 핵심 루프의 시작과 종료 조건

## 이 문서가 소유하지 않는 정보

- 지역별 콘텐츠
- 개별 아이템 수치
- 시스템 구현 코드

## [요구·채택 방향]

준비 → 탐험 → 전투/파밍 → 보상 → 귀환 → 정리·성장·꾸미기 → 더 어려운 목표.

집과 모험이 따로 놀지 않고 모험의 결과가 공간과 장비에 남게 한다.

## [제안]

- 기본 채집은 도구 중심의 짧고 분명한 행동으로 시작한다. 별도 생활 스킬 레벨은 초본 후 검토한다.
- 낮밤은 위험·귀환·휴식의 리듬을 만드는 후보이며, 배고픔·체온 등 여러 관리 게이지를 자동 추가하지 않는다.
- 실패에도 캐릭터 성장과 장기 창작물이 무조건 지워지는 구조를 기본값으로 삼지 않는다.

## [미정]

- 밤의 효과
- 사망 시 손실과 회수 방식
- 가방 용량
- 회복과 귀환 수단
- 채집 자원의 재생 방식

집을 옮길 이유를 만들기 위해 단순 왕복 노동을 과도하게 늘리지 않는다. 정확한 규칙은 별도로 결정한다.
