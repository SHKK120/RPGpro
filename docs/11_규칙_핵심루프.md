# 핵심 플레이 루프 규칙

## 문서의 역할

플레이어가 반복해서 수행하는 핵심 플레이 흐름을 정의한다.

## 이 문서가 소유하는 정보

- 핵심 행동의 반복 구조
- 행동, 보상, 성장의 연결 관계
- 핵심 루프의 시작과 종료 조건

## 이 문서가 소유하지 않는 정보

- 지역별 콘텐츠
- 개별 아이템 수치
- 시스템 구현 코드

## [요구·채택 방향]

준비 → 탐험 → 전투/파밍 → 보상 → 귀환 → 정리·성장·꾸미기 → 더 어려운 목표.

집과 모험이 따로 놀지 않고 모험의 결과가 공간과 장비에 남게 한다.

## [제안]

- 기본 채집은 도구 중심의 짧고 분명한 행동으로 시작한다. 별도 생활 스킬 레벨은 초본 후 검토한다.
- 낮밤은 위험·귀환·휴식의 리듬을 만드는 후보이며, 배고픔·체온 등 여러 관리 게이지를 자동 추가하지 않는다.
- 실패에도 캐릭터 성장과 장기 창작물이 무조건 지워지는 구조를 기본값으로 삼지 않는다.

## [미정]

- 밤의 효과
- 사망 시 손실과 회수 방식
- 가방 용량
- 회복과 귀환 수단
- 채집 자원의 재생 방식

집을 옮길 이유를 만들기 위해 단순 왕복 노동을 과도하게 늘리지 않는다. 정확한 규칙은 별도로 결정한다.

## [M04 시험 선택]

Green Coast의 첫 Vertical Slice에서 거점 준비 → 채집·일반 전투 → Monster Core +1 성장 → Ruin Guard → 같은 지역의 첫 보스 → 고유 보상 → 귀환 → Trophy 전시 → Blade +2 → 저장·계속하기를 한 바퀴로 연결한다.

보스 격파 뒤 성취가 거점 공간과 장비에 함께 남는지를 보는 M04 한정 시험이다. 모든 보스가 Trophy와 강화 재료를 함께 주는 규칙, 반복 파밍, 정식 사망 손실과 최종 성장 구조를 확정하지 않는다. 실제 구현·검증·사람 확인 범위는 `M04_첫보스_트로피_완결루프.md`가 기록한다.

## [MACRO-01 시험 선택]

기존 첫 지역 완결 뒤 Home에서 두 번째 지역을 열고, 새 자원·적·Vista·집터를 발견한 다음 Home 제작 결과와 저장·계속하기까지 돌아오는 전체 골격을 시험한다. 세부 규칙의 최종 채택이 아니라 게임 시스템의 위치와 연결을 확인하는 단계다.
