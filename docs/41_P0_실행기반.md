# P0 실행 기반

## 목표

Godot 프로젝트를 실행해 바닥, 고정 카메라, 실제 조명, 임시 캡슐 하나와 상자 두 개가 표시되고 종료 후 같은 메인 씬을 다시 열 수 있는지 확인한다.

## 이번 임시 선택

- Godot `4.7.2.stable.official.ed1daf0bf`
- Compatibility (`gl_compatibility`) 렌더러
- 1280×720 일반 창 모드
- 원근 투영의 높은 사선 고정 카메라
- 엔진 내장 메시와 기본 재질만 사용한 정적 장면

이 값은 P0 시험용이다. 최종 렌더러, 아트 규격, 캐릭터 표현, P1 이동·카메라 입력, 전투 방식은 결정하지 않는다.

## 여는 방법

1. Godot 프로젝트 관리자에서 `C:\Users\CKIRUser\RPGpro\project.godot`를 가져와 연다. 또는 `C:\godot\godot.exe --editor --path C:\Users\CKIRUser\RPGpro`를 실행한다.
2. F6가 아니라 프로젝트 실행(F5)으로 `res://scenes/prototype/p0_bootstrap.tscn` 메인 씬을 연다.
3. 정지(F8)하고 에디터를 닫는다.
4. 같은 프로젝트를 다시 열어 F5로 재실행한다.

## 기술 확인

- Godot 실행 파일과 버전: 직접 확인 완료.
- `--headless --path C:\Users\CKIRUser\RPGpro --import`: 오류 없이 완료.
- `--headless --path C:\Users\CKIRUser\RPGpro --quit-after 3`: 메인 씬 로드 오류 없이 완료. `--quit-after`의 값은 초가 아니라 반복 횟수다.
- 일반 그래픽 모드에서 `RPGpro P0 (DEBUG)` 창 생성과 종료를 확인했다.
- 해당 실행을 종료한 뒤 같은 프로젝트 경로를 일반 그래픽 모드로 다시 실행해 메인 씬이 오류 없이 로드되는 것을 확인했다. 에디터를 닫았다 다시 여는 사람의 F5 확인과는 구분한다.
- 일반 그래픽 모드의 Movie Maker 1프레임 출력: 1280×720 Compatibility 렌더 완료. 바닥·캡슐·상자 두 개와 서로 다른 형태·깊이·그림자가 출력 이미지에서 확인됐다.
- 그래픽 출력 장치: OpenGL ES 3.0 Compatibility, Intel HD Graphics 530에서 ANGLE 사용. 드라이버의 OpenGL 3.3 품질 경고가 있었으나 그래픽 프레임 출력은 완료됐다.
- headless 상태에서 Movie Maker를 함께 사용한 보조 시도는 dummy renderer의 `texture_2d_get` null 오류와 signal 11로 실패했다. 일반 그래픽 출력 성공과 구분하며, P0 프로젝트·씬 로드 오류로 판정하지 않는다.
- 구현 당시 사람의 실제 창 가독성, F8 종료, 에디터를 닫았다 다시 여는 F5 재실행은 미확인으로 남겼다. 이후 위 사용자 보고로 P0 실행 기반 확인을 완료했으며 자동·출력·명령 재실행 결과와 구분한다.
