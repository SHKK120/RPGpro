# 가구 테마

## 문서의 역할

가구 테마의 분류와 콘텐츠 구성을 정의한다.

## 이 문서가 소유하는 정보

- 가구 테마의 정의와 구분
- 테마별 가구 콘텐츠
- 테마 간 관계

## 이 문서가 소유하지 않는 정보

- 집과 가구 배치의 공통 규칙
- 일반 아이템 분류 체계
- 가구 구현 코드

## [요구·채택 방향]

테마를 콘텐츠 확장의 기본 묶음으로 삼고 집의 내부와 외부에 표현한다.

## [제안] 예시

- 테마 후보: Basic Wood, Forest, Coastal, Gothic, Mushroom, Nordic
- 구성 후보: 침대, 의자, 책상, 조명, 카펫, 벽 장식, 소품, 외장재

이 이름과 구성은 출시 목록, 제작 의무, 테마당 고정 개수로 확정하지 않는다.

## [제안]

- 같은 설치 규격을 공유하는 외형·재질 변화와 새 기능을 요구하는 가구를 구분한다.
- 기존 슬롯에 맞는 새 외형은 콘텐츠 추가로, 처음 등장하는 전시·보관 방식 등은 시스템 변경으로 구분해 별도 조각을 잡는다.
- 테마 사용에 전투 능력치 세트 최적화를 강제하지 않는 방향을 선호한다.
