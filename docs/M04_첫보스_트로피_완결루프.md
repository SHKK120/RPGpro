# M04 첫 보스·트로피·귀환 완결 루프

## 상태

`M04 — 첫 보스·트로피·귀환 완결 루프 구현완료·사람확인대기`

M03의 사람 플레이 확인과 ART-01의 최종 스타일 확인은 아직 완료되지 않았다. M04가 기술적으로 연결됐다는 사실과 전투 감각·난이도·시각 만족의 사람 판정을 구분한다.

## 범위와 실행

- 실행 장면: `res://scenes/prototype/green_coast_m02.tscn`
- 실행: `C:\godot\godot.exe --path C:\Users\CKIRUser\RPGpro` 또는 편집기 F5
- 기존 M02 메인 장면을 유지하고 `m04_green_coast.gd`가 M03을 상속한다.
- Green Coast 동쪽 폐허 너머를 같은 지역의 작은 평면 Arena로 확장했다. 새 Region·던전·범용 Boss Framework는 만들지 않았다.
- 동쪽 외곽 울타리의 Arena 통로 두 칸을 비우고 짧은 울타리·청록 문틀로 양옆을 다시 연결했다. 접근 잠금문과 전투 장벽은 안쪽이 아니라 같은 외곽 입구 `X=14.82`에 나타난다.
- Ruin Guard를 쓰러뜨려 M03 첫 전투 루프를 완료하면 동쪽 청록 장벽이 열리고, Arena 안쪽에 들어가면 보스전이 자동 시작된다.

## [M04 시험 선택] Boss와 Arena

`Tidebound Guardian`은 Godot 기본 메시로 만든 임시 실루엣이며 HP 300, 접촉 피해 없음, Arena 내부 이동을 사용한다.

| Phase | 패턴 | 시험 판정 |
|---|---|---|
| 1 | Sweep | 0.65초 예고, 정면 부채꼴 2.2m, 피해 20, 회복 0.65초 |
| 1·2 | Slam | 0.9초 원형 바닥 경고, 반경 2.5m, 피해 24, 회복 0.8초 |
| 2 | Tide Burst | 0.7초 예고 뒤 비유도 투사체 3발, 각 피해 10, 속도 7.5m/s |

HP 50% 이하에서 피해 없는 짧은 Phase 2 신호를 한 번 보여 준다. 직전 패턴을 후보에서 빼 즉시 반복하지 않는다. Sweep은 예고 시작 방향을 고정해 뒤로 피하면 맞지 않고, Sweep·Slam은 물리 레이로 벽 너머 피해를 거부한다. Tide Burst는 기존 M03 투사체를 재사용해 환경 또는 플레이어와 한 번 충돌하면 제거된다.

입장 시 자동 이동과 표식을 취소하고 Boss HUD·이름·출구 장벽을 표시한다. 전투 중 우클릭 목적지는 Arena 범위 안에서만 받는다. WASD·좌클릭·Space 회피와 기존 추적 카메라는 유지한다.

## 사망·격파·보상

- 보스전 중 사망하면 보스 공격과 모든 투사체를 즉시 정리하고 HUD·장벽을 숨긴다.
- 치명타 신호가 보스 공격 함수 안에서 발생할 때는 전투 상태만 먼저 비활성화하고, 충돌·투사체·보스 초기화는 다음 idle 단계에 수행해 같은 호출 스택의 재진입을 피한다.
- 보스는 Spawn 위치, HP 300, Phase 1, Dormant 상태로 복구되고 플레이어는 M03 규칙대로 거점에서 HP 100으로 돌아온다.
- 다시 Arena에 들어가면 새 전투가 시작된다. 사망 복귀 대기 중 즉시 재진입하지 않는다.
- 최초 격파 시 `boss_defeated`를 먼저 저장하고 장벽을 영구 개방한 뒤, Arena 안전 위치에 보이는 E 상호작용 보상을 생성한다.
- 미수령 상태로 종료하면 Continue에서 보스는 되살아나지 않고 보상만 다시 나타난다.
- E로 수령하면 고유 `Tide Crest`와 `Tide Core`가 한 번에 지급되고 `boss_reward_claimed`가 저장된다. 중복 수령은 막는다.

## 귀환·전시·두 번째 성장

보스 격파 뒤 열린 기존 입구를 통해 가까운 거점으로 돌아간다. 새 Fast Travel이나 Teleport 메뉴는 만들지 않았다.

거점의 고정 Tide Crest 받침에서 E를 누르면 Trophy를 한 번 전시하고 실제 청록색 세 갈래 Crest가 공간에 남는다. 기존 M02 기념품 전시 구조와 같은 Interactables/E 경계를 사용하되 자유 배치 시스템은 추가하지 않았다.

기존 무기 작업대에서 Blade +1과 Tide Core가 있을 때 +2로 강화한다. Tide Core 소비와 `weapon_level = 2`를 같은 상태 변경에서 적용하고 피해를 24에서 30으로 올린다. 이미 +2면 다시 소비하지 않는다. Trophy 전시와 +2까지 끝나면 `green_coast_first_loop_completed`가 참이 된다.

## 저장 호환

별도 M04 Save를 만들지 않고 기존 M02/M03 버전 1 저장에 다음 선택 키를 추가했다.

- `boss_defeated`
- `boss_reward_claimed`
- `boss_trophy_owned`
- `boss_trophy_displayed`
- `boss_growth_core_owned`
- `green_coast_first_loop_completed`

키가 없는 M02/M03 저장은 안전한 `false` 기본값으로 로드한다. 보스의 현재 HP·Phase·공격·Projectile·전투 중 Arena 상태는 저장하지 않는다. 격파·수령·전시·+2·완료 사이의 모순 상태는 검증에서 거부한다.

## 기술 확인

- Godot 4.7.2의 headless 파싱과 메인 장면 실행, 일반 1280×720 Compatibility/ANGLE 렌더를 확인했다.
- 기존 지역과 Arena의 Navigation map 경로 연결, Arena 내부 목적지 수락, 전투 중 외부 목적지 거부, 전투 종료 뒤 전역 우클릭 복구를 확인했다.
- 자동 Arena 진입, Boss HUD와 시각 장벽, Sweep 정면 20·뒤쪽 비명중, Slam 경고 후 24, Phase 2 한 번 전환과 Tide Burst 3발을 물리 프레임에서 확인했다.
- 플레이어 사망 뒤 Boss HP·Phase·HUD·장벽·투사체 초기화와 거점 복귀, 재진입, 최초 격파를 확인했다.
- 격파 직후 저장, 미수령 보상 Continue 복원, E 보상 지급, 거점 E 전시, Tide Core 1회 소비와 Blade +2 피해 30, 완결 상태 저장·로드를 격리 경로에서 확인했다.
- 새 키가 없는 M03 저장 검증, M03 단독 스크립트의 우클릭·근접 공격·사망 복귀·최대 무기 단계 1, M02 채집·기념품·전시 노드, 기존 적 5체와 Vista 보존을 확인했다.
- 실제 사용자 `user://prototypes/green_coast_m02` 저장은 격리 시험에 사용하거나 M04 코드로 저장하지 않았다. 현재 파일도 M04 선택 키가 없는 기존 M03 내용이다.
- 사용자 보고 보완 뒤 보스 Slam 호출 스택 안에서 치명타를 발생시켜 장면 유지, 다음 프레임 보스 정리, 1.35초 뒤 HP 100·거점 복귀를 다시 확인했다. 외곽 입구의 울타리 개구부·문/장벽 좌표·문틀 연결을 자동 검사했고 일반 Compatibility/ANGLE 화면에서도 통로가 연속 울타리와 구분되어 보이는 것을 확인했다.

직접 함수·격리 자동 진단과 실제 OS 키·마우스 감각은 구분한다. 보스 텔레그래프의 체감 가독성, 회피 타이밍, 짧은 전투의 난이도와 재미, Trophy의 최종 시각 만족은 사람 확인 전 통과 처리하지 않는다.

## 사람이 한 번에 확인할 것

### A — Boss Fight

- Ruin Guard 완료 뒤 동쪽 Arena에 들어가 Boss HUD와 출구 장벽이 나타나는지 본다.
- 동쪽 외곽 울타리의 청록 문틀이 입구로 명확히 보이고, 잠금문과 전투 장벽이 그 입구에서 열리고 닫히는지 본다.
- Sweep·Slam·Phase 2·Tide Burst의 예고와 회피, 피격, 사망·거점 복귀·재도전, 최종 격파가 자연스러운지 확인한다.

### B — 성취와 귀환

- 보이는 보상을 E로 획득하고 거점에 돌아와 Tide Crest를 전시한다.
- 기존 작업대에서 Tide Core로 Blade +2를 만들고 Trophy가 실제 공간에 남는지 본다.

### C — 보존

- 저장 후 종료·계속하기에서 보스가 진행 대상으로 되살아나지 않고 Trophy와 Blade +2가 유지되는지 확인한다.
- 기존 채집·일반 전투·자동 절벽 Vista·우클릭 이동이 그대로인지 본다.
