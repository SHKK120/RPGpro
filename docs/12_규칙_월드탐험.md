# 월드 탐험 규칙

## 문서의 역할

월드에서 이동하고 발견하며 탐험하는 공통 규칙을 정의한다.

## 이 문서가 소유하는 정보

- 월드와 탐험의 공통 구조
- 발견과 접근에 관한 규칙
- 탐험 보상의 원칙

## 이 문서가 소유하지 않는 정보

- 개별 지역의 목록과 상세 정보
- 전투 세부 규칙
- 월드 생성 구현

## [제안] 현재 방향

- Handcrafted Connected Open-Zone: 지역 단위 공간들을 길과 통로로 연결한다.
- 큰 지형, 길, 절벽, 바다, 주요 목적지, 전망, 집터는 구도를 직접 설계한다.
- 소품, 식생, 일부 자원은 절차적 배치를 사용할 수 있지만 초본의 필수 생성기가 아니다.
- Landmark, Secret, Vista를 구분한다.
- Vista에서는 카메라가 전환되어 바다, 태양, 해안의 움직임 등을 보여준 뒤 평상시 시점으로 복귀한다.
- 먼 주요 목적지 중 일부는 실제로 찾아갈 수 있게 한다. 모든 배경을 플레이 공간으로 만들지는 않는다.

## [미정]

- 지역 이동과 로딩 방식
- 자원 재생과 지역 재방문 상태
- 경관 보존 영역
- 멀리 보이는 움직임의 표현 수준

## [MACRO-01 시험 선택]

두 번째 지역은 별도 NavigationRegion을 가진 작은 고지대 순환 공간으로 시험한다. 기존 자동 Vista 규칙을 재사용하며 Landmark, 새 자원, 강한 적, 집터 후보와 귀환 통로를 둔다. 정식 지역 이동·로딩 방식은 아직 닫지 않는다.

## [MASTER-03 Green Coast Production 적용]

실제 Green Coast는 Home/Village, Forest/Nature, Ruins/Secret, Combat, Cliff Path, Beach/Coast, Vista/Watchtower, Boss Area가 한 Navigation 흐름에 이어지는 작은 Handcrafted Connected Open-Zone으로 유지한다. 기존 주 loop, 좁은 return shortcut, secret과 Boss route를 Production 환경 자산으로 시각화했으며 기능 위치와 Save ID는 바꾸지 않았다. 이 배치는 첫 지역 Production Base이고 모든 Region의 최종 크기·로딩 방식·자원 재생 규칙을 확정하지 않는다.
