# 닫을 것

## 문서의 역할

구현 전에 사람이 결정해야 하는 미정 사항을 관리한다.

## 이 문서가 소유하는 정보

- 아직 답이 정해지지 않은 결정
- 결정을 닫기 위해 필요한 질문
- 결정 상태와 근거

## 이 문서가 소유하지 않는 정보

- 확정된 시스템 규칙
- 단순 구현 작업 목록
- 후순위 아이디어

모든 질문을 첫 실행의 선행 조건으로 삼지 않는다. 이미 직접 확인된 Godot 실행 경로와 버전은 `01_환경복구.md`가 소유하며 여기서 다시 선택하지 않는다.

## 첫 실행·시각 시험 전에 닫을 것

### Q-001 — 사용할 렌더러

- 질문: P0에서 사용할 Godot 렌더러는 무엇인가?
- 현재 제안: P0 첫 실행 시험에는 Compatibility (`gl_compatibility`)를 사용한다. 본격 시각 시험과 에셋 채택 전 Forward+ 등의 지원 여부와 표현 차이를 확인한다.
- 상태: [P0 시험 선택·최종 미정]
- 안 정하면 막히는 조각: P0 실행 기반에는 임시 선택 완료. 최종 시각 렌더러는 Q-004 검토 전까지 미정
- 관련 정본: `01_환경복구.md`, `14_아트스타일.md`
- 결정 기록: P0 지시에서 Compatibility를 첫 실행용으로 선택했다. 실제 동작 확인과 최종 렌더러 결정은 별개다.

### Q-002 — 임시 시점과 캐릭터 표현

- 질문: 첫 시각 시험의 임시 투영·카메라 각도와 캐릭터 표현은 무엇인가?
- 현재 제안: P1-3은 P0·P1-2의 높은 사선 원근 투영·회전·FOV와 노란 캡슐을 유지하면서 카메라 위치만 플레이어 XZ를 짧은 지연으로 따라가게 시험한다. 수동 회전·줌은 넣지 않으며 캐릭터의 3D 모델·2D 스프라이트 여부와 최종 카메라는 정하지 않았다.
- 상태: [P1-3 시험 선택·최종 미정]
- 안 정하면 막히는 조각: P1-3에는 임시 선택 완료. 이후 시각 시험의 최종 캐릭터와 카메라는 미정
- 관련 정본: `14_아트스타일.md`
- 결정 기록: P1-1 지시에서 캡슐과 P0 고정 시점을 최소 이동 시험에 한정해 선택했다. P1-3 지시에서 같은 구도의 수평 위치 추적만 별도 시험으로 선택했다.

### Q-003 — 기본 입력과 실행 확인 방식

- 질문: P0의 실행·종료·다시 열기 확인 방식은 무엇이며, P1의 기본 이동 입력과 플레이 중 카메라 조작은 무엇인가?
- 현재 제안: P0 실행, P1-1 최소 이동과 P1-2 고정 시험장 우클릭 목적지 이동 확인은 완료했다. P1-3은 기존 입력을 유지한 추적 카메라를 시험하며 부드러운 추적과 추적 중 클릭 정확도를 확인했다. P1-4는 현재 평면 시험장에 한해 바닥·고정 상자·외곽 막이·바닥 밖 배경 클릭을 가까운 도달 가능 경로 끝점으로 보정한다. 우클릭과 WASD의 최종 병행, 공격·채집·상호작용 입력과 최종 카메라 조작은 정하지 않았다.
- 상태: [P0·P1-1·P1-2 확인 완료·P1-3 부분 확인·P1-4 시험 선택·최종 입력 미정]
- 안 정하면 막히는 조각: P1-4에는 평면 시험장 목적지 보정으로 임시 선택 완료. 이후 P1의 최종 입력·상호작용 우선순위와 플레이 중 카메라 조작은 미정
- 관련 정본: `01_환경복구.md`, `14_아트스타일.md`, `15_전투.md`
- 결정 기록: E 외부 검토에서 P0와 P1의 결정 시점을 구분했다. P0 실행과 P1-1 최소 이동, P1-2 고정 시험장 우클릭 목적지 이동 확인을 완료했다. P1-3 지시에서 새 입력 없는 추적 카메라를 시험했고, P1-4 지시에서 사용성 요청에 따라 보정 가능한 무효 클릭 일부를 도달 가능한 목적지로 바꾸는 평면 시험을 선택했다.
