# MASTER-01 — Visual Baseline → First Game Skeleton

## 실행 원칙

- 이 문서는 M05 Visual Baseline과 후속 MACRO-01을 한 흐름으로 잇는 기준 문서다.
- 현재는 PHASE A만 실행한다. PHASE B는 사람이 아래 세 묶음을 확인하고 계속 진행을 명시한 뒤 시작한다.
- M04는 현재 구현을 회귀 확인에 사용하지만, 별도 사람 확인이 없으므로 사람 확인 완료로 기록하지 않는다.
- Compatibility 렌더러, 기존 플레이어 루트·충돌·내비게이션·전투·저장 구조를 유지한다.

## PHASE A — M05 Visual Baseline

상태: **M05 — Visual Baseline 보완완료·사람확인대기**

### 고정 대표 프레임

1. **Gameplay**: 시작 산책로에서 플레이어, 근접·원거리·정예 적, 숲·폐허·바다를 함께 본다.
2. **Home**: 집·작업대·휴식 조명·전리품·트로피를 한 화면에서 본다.
3. **Vista**: 절벽 끝 자동 전망에서 전경 해안, 중경 바다, 원경 바위섬의 깊이를 본다.

### 적용한 기준선

- 작은 화면에서도 실루엣이 먼저 읽히도록 플레이어를 청록색 상의, 황토색 후드·망토, 밝은 얼굴과 어두운 부츠의 저폴리 여행자로 분리했다.
- 집의 관통하던 단일 지붕을 두 경사면과 용마루로 교체했다. 플레이어에는 보행 흔들림을 추가하고, 마우스 방향을 8방향으로 고정해 오른쪽 어깨·팔·손·검이 함께 휘두르도록 했다.
- 캐릭터는 최종 2D 픽셀 단면으로 교체할 수 있게 방향 인덱스와 시각 자식을 분리했다. 현재 3D 여행자는 동작 검증용이며, Cloth/Outer Cloth/Leather/Skin/Metal 재질 슬롯은 이후 텍스처 적용 기준이다.
- 근접 적은 낮고 넓은 갑각형, 원거리 적은 떠 있는 물방울형, 정예는 방패를 든 직립형, 보스는 넓은 어깨와 가면·볏을 가진 대형 실루엣으로 구분했다.
- 바위·나무·관목·목재·울타리·폐허는 기존 Green Coast 에셋을 재사용하고, Ground/Soil/Stone/Cliff/Wood/Leaf/Ruin/Accent/Shore/Water 재질군으로 색과 표면을 묶었다.
- 지면은 낮은 채도의 올리브·갈색, 바다는 어두운 청록·청회색, 강조색은 황토와 제한된 청록으로 정리했다.
- 바다는 저비용 정점 파동과 넓은 색 띠만 사용했다. 원경 바위 아래 얕은 섬 받침과 세 번째 실루엣을 추가해 전망의 전경·중경·원경을 분리했다.
- 집의 휴식 지점에는 약한 따뜻한 국소광을 더했고, 전리품·목적지·트로피 발광은 정보 전달에 필요한 정도로 낮췄다.
- Blender 재작업, 외부 에셋 다운로드, 새 플러그인·외부 AI·유료 서비스는 사용하지 않았다.

### 보존한 게임 구조

- 플레이어 루트, 캡슐 충돌체, NavigationAgent, 이동·우클릭·회피·공격·피격·저장 로직은 그대로 두고 시각 자식만 런타임에 분리했다.
- 적의 AI·체력·공격 판정·드롭과 보스 진행 조건은 유지하고 메시 실루엣만 교체했다.
- 해안 경계, 절벽 끝 자동 전망 진입/이탈, 보스 외곽 입구와 문, 사망 후 복구 흐름을 유지한다.

### 기술 확인과 사람 확인의 구분

- 기술 확인: Godot 4.7.2 파싱과 Compatibility/ANGLE 일반 그래픽 실행, Gameplay/Home/보행/공격 고정 프레임을 확인했다. 지붕 2면, 8방향 인덱스, 보행 관절, 오른쪽 무기 피벗, 공격 종료 복귀와 치명 피해 뒤 장면 유지·HP 100 거점 복귀를 실행 중 검사했다. M04 사람 확인 상태는 승격하지 않는다.
- 사람 확인 대기: 아래 A/B/C의 화면 인상과 앞으로 전체 게임을 확장할 기준으로 충분한지는 사람이 판단한다.

### 사람이 한 번에 확인할 항목

- **A — Gameplay**: 플레이 화면이 단순 시험장이 아니라 게임처럼 충분히 읽히는가.
- **B — Home/Vista**: 집은 따뜻한 귀환점으로, 전망은 전경·중경·원경이 있는 해안으로 읽히는가.
- **C — 확장 기준선**: 이 품질과 제작 비용으로 전체 게임 골격을 먼저 넓혀도 충분한가.
