# M03 — 첫 전투·위험·성장 루프

## 상태

`M03 — 첫 전투·위험·성장 루프 구현완료·사람확인대기`

M02의 거점·숲·폐허·해안과 채집·귀환·저장을 유지한 채 첫 전투, 위험, Monster Core, 무기 강화와 시험 엘리트를 한 지역에 연결했다. 아래 조작과 수치는 모두 `[M03 시험 선택]`이며 정식 전투·사망·성장 규칙을 확정하지 않는다.

## 실행과 조작

- 메인 장면: `res://scenes/prototype/green_coast_m02.tscn`
- Godot에서 F5로 실행해 새 시험 또는 계속하기를 선택한다.
- 이동: WASD 또는 우클릭
- 공격: 마우스 왼쪽 클릭. 화면에서 가리킨 월드 XZ 방향으로 Prototype Blade를 한 번 휘두른다.
- 회피: Space. 현재 WASD, 현재 이동, 최근 전투 방향 순으로 약 1.5m를 0.18초 동안 이동한다.
- 상호작용: E. 기존 채집·기념품·벤치·전시와 Core·무기 작업대·휴식을 같은 근접 상호작용으로 처리한다.
- 메뉴: Esc
- 북쪽 절벽 전망: 기존 M02처럼 끝자락 접촉 중 자동 활성화한다. 전망과 전환 중에는 공격·회피를 받지 않는다.

공격은 기존 우클릭 자동 이동과 표식을 취소하지만 WASD 이동을 얼리지 않는다. 회피는 자동 이동을 취소하고 0.16초 무적, 0.8초 재사용 대기를 가진다. 공격 중 회피와 회피 중 공격은 이번 시험에서 허용하지 않는다.

## 플레이 루프

1. 거점에서 HP 100, Prototype Blade +0으로 시작한다.
2. 숲의 Coast Crawler 2개와 폐허의 Ruin Wisp 2개를 상대한다.
3. 사망한 적이 떨어뜨린 Monster Core를 기존 E 상호작용으로 줍는다.
4. Core 4개를 모아 거점 무기 작업대에서 한 번 강화한다. Core 4개와 `weapon_level = 1`은 한 상태 변경으로 처리한다.
5. 필요하면 거점 Rest Point에서 HP를 최대로 회복한다.
6. 폐허 깊은 곳의 Ruin Guard를 강화된 피해로 쓰러뜨려 첫 전투 루프를 완료한다.
7. 저장 후 종료하고 계속하기로 Core 수량, 무기 단계와 완료 상태를 복구한다.

HP가 0이 되면 공격·자동 이동·입력을 정지하고 짧은 사망 표시 뒤 거점 안전 시작점으로 복귀한다. HP와 적은 최대 상태로 초기화하지만 목재·돌·기념품·Core·무기 강화·전투 완료는 잃지 않는다. 미획득 Core 드롭과 투사체는 정리한다.

## 적과 시험 수치

| 적 | 수 | HP | 이동 | 피해 | 감지 | 공격 | 예고/쿨다운 | 보상 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| Coast Crawler | 2 | 40 | 2.6 | 12 | 7m | 근접 1.4m | 0.45초 / 1.0초 | Core 1 |
| Ruin Wisp | 2 | 50 | 2.2 | 10 | 9m | 4~7m 투사체, 7m/s | 0.65초 / 1.8초 | Core 1 |
| Ruin Guard | 1 | 110 | 2.3 | 18 | 7.5m | 근접 1.7m | 0.65초 / 1.15초 | Core 3 |

- Crawler와 Guard는 같은 근접 상태 기계를 수치만 바꿔 재사용한다.
- 근접 상태: Idle → Chase → Windup → Attack → Recover, Leash/Safe Zone에서는 Return, 사망 시 Dead.
- Wisp 상태: Idle → Chase/거리 확보 → Windup → Projectile → Recover, 나머지 Return/Dead 경계는 공통이다.
- 모든 적은 고정 배치이고 약 9~10m Leash를 사용한다. 거점 Safe Zone에 있는 플레이어는 추격하거나 공격하지 않는다.
- Spawn으로 복귀하면 위치와 HP를 초기화한다. 런타임 웨이브·랜덤 스포너·범용 AI 프레임워크는 만들지 않았다.

## 공격·피격 피드백

- 플레이어 옆에 밝은 기본 BoxMesh 검을 표시하고 0.28초 스윙한다. 0.09초 시점에 한 번만 판정한다.
- 기본 피해는 16, 강화 뒤 24, 사거리 1.6m, 재사용 대기는 0.45초다.
- 한 스윙은 가장 가까운 유효 적 한 개에 한 번만 피해를 준다.
- 플레이어와 적의 공격은 물리 레이로 벽 너머 판정을 거부한다.
- 적은 공격 전에 크기와 emission이 변하고, 피격 시 흰색 Flash와 짧은 충돌 기반 Knockback을 보인다.
- Wisp 투사체는 플레이어와 환경 충돌 뒤 제거되고 4초 뒤에도 자동 제거된다.
- 적 사망은 몸체가 눌리며 사라지고 충돌을 비활성화한 뒤 청록색 Core를 남긴다.
- 플레이어 피격 Flash, 사망 오버레이, Core·강화 Toast를 연결했다.

적 체력바와 Damage Number는 SHOULD 항목으로 남겼다. MUST 흐름을 위해 별도 UI·데이터 체계로 확장하지 않았다.

## 저장 호환

기존 M02 `save_v1.json`을 그대로 사용하며 별도 Combat Save를 만들지 않는다. 기존 버전 1 형식에 다음 선택 키만 추가한다.

- `monster_core_count`
- `weapon_level`
- `first_combat_loop_completed`

세 키가 없는 기존 M02 저장은 각각 `0`, `0`, `false`로 정상 로드한다. 현재 HP, 적 HP·위치·사망, Core 드롭, 투사체, Aggro, 쿨다운은 저장하지 않는다. 기존 지역·위치·목재·돌·획득 ID·기념품·벤치·전시 필드와 검증 후 교체·이전 정상본 정책은 유지한다.

## 기술 확인

- Godot 4.7.2 Compatibility에서 메인 장면 파싱과 일반 1280×720 그래픽 실행을 확인했다.
- 고정 적 5개와 거점 작업대·Rest Point가 M02의 기존 지역 안에 생성되고 새 Region이나 NavMesh 재베이크가 없음을 확인했다.
- 실제 물리 프레임에서 Crawler 예고·근접 피해, Wisp AI 예고·투사체 피해, Safe Zone 복귀를 확인했다.
- 좌클릭 입력, 기본 공격 16, 단일 타격, 벽 차단, 피격 Flash·Knockback·사망 충돌 해제를 확인했다.
- Space 회피의 무적과 서쪽 경계 충돌 정지, 회피/공격 상호 배제, 메뉴·Vista 전투 차단을 확인했다.
- 일반 적 네 마리의 Core 4개 획득, 원자적 +1 강화, 피해 24, Guard 5회 타격 처치와 완료 저장을 확인했다. Core 부족 시 상태를 바꾸지 않는 분기는 코드 경계로 유지했다.
- 사망 뒤 HP 100·안전 시작점·적 Spawn 초기화, 전투·M02 진행 무손실을 확인했다.
- 격리 저장에서 M02 채집·기념품·벤치·전시와 M03 Core·강화·완료를 함께 저장하고 계속하기로 복구했다.
- 새 전투 키가 없는 M02 저장을 별도 격리 파일로 불러와 기본값과 기존 목재·돌 상태가 유지됨을 확인했다.
- M03 플레이어에서도 실제 WASD와 카메라 투영 우클릭 이벤트 이동을 확인했다.
- 실제 사용자 `user://` 저장은 시험에 사용하거나 덮어쓰지 않았다.

직접 함수·엔진 이벤트 진단과 실제 OS 마우스·키 조작 감각은 구분한다. 적 배치의 체감, 전투 난이도, 회피 타이밍, 강화 전후 손맛과 장시간 플레이는 사람 확인 전 통과 처리하지 않는다. Intel HD 530의 기존 OpenGL 경고와 ANGLE 전환은 유지된다.

## 사람이 한 번에 확인할 것

### A — 전투 감각

- 좌클릭 공격, WASD·우클릭 이동과 Space 회피가 서로 자연스럽게 전환되는지 본다.
- Crawler의 근접 예고, Wisp의 원거리 예고·투사체, 피격과 사망·거점 리스폰이 읽히는지 확인한다.

### B — 성장 루프

- 일반 적을 처치해 Core 4개를 E로 줍고 거점에서 회복·무기 강화를 한다.
- 강화 전후 피해 차이를 느낀 뒤 Ruin Guard를 처치해 `첫 전투 루프 완료`가 표시되는지 본다.

### C — 기존 게임 보존

- 채집·기념품·벤치·전시, 절벽 자동 전망과 벽·사물 우클릭 보정이 그대로인지 본다.
- 저장 후 종료·계속하기에서 M02 진행과 Core·Blade +1·전투 완료가 함께 유지되는지 확인한다.
