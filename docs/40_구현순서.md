# 구현 순서

## 문서의 역할

현재 진행할 조각(Slice)과 이후 조각의 순서를 관리한다.

## 이 문서가 소유하는 정보

- 조각의 진행 순서
- 현재 조각의 범위
- 조각별 시작 및 완료 조건

## 이 문서가 소유하지 않는 정보

- 게임 디자인 결정
- 기능의 상세 구현 방법
- 후순위 아이디어 목록

## 운영 상태

- 문서 뼈대: [확인 사실/직접 확인] `AGENTS.md`와 초기 `docs/` 문서가 존재한다. 이번 작업 시작 시 Git에는 `AGENTS.md`와 `docs/`가 미추적 상태였다.
- `DOC-02 / A`: 사용자 확인 완료
- `DOC-02 / B`: 외부 본문 검토 적합 — 문서 이관. 제안과 미정은 승인된 규칙으로 승격하지 않았다.
- 현재 조각: `DOC-02 / C`
- 상태: 외부 본문 검토 적합 — 문서 이관. 제안과 미정은 승인된 규칙으로 승격하지 않았고 실제 플레이·시각·재미를 통과 처리하지 않았다.
- D~E: 미수행
- 다음 행동: 사용자가 `DOC-02 / D`를 별도로 지시할 때까지 멈춘다.
- 중단 지점: A~C 문서 이관과 외부 문서 검토가 끝났다. C의 제안과 미정은 채택 또는 사람 판정 전이며, 에셋 도구 연결·다운로드와 게임 구현은 수행하지 않았다.
- 보존 상태: A~C 승인 문서 21개의 중간 보존을 승인받았다. commit/push와 원격 확인의 실제 결과는 해당 작업의 최종 보고에 남긴다.

문서 작성만으로 게임 기능을 통과 처리하지 않는다. 커밋·원격 확인 결과는 해당 작업의 최종 보고에 남긴다.
