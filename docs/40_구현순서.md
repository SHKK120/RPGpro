# 구현 순서

## 문서의 역할

현재 진행할 조각(Slice)과 이후 조각의 순서를 관리한다.

## 이 문서가 소유하는 정보

- 조각의 진행 순서
- 현재 조각의 범위
- 조각별 시작 및 완료 조건

## 이 문서가 소유하지 않는 정보

- 게임 디자인 결정
- 기능의 상세 구현 방법
- 후순위 아이디어 목록

## 운영 상태

- 문서 뼈대: `AGENTS.md`와 초기 `docs/` 문서가 존재한다. 초기 생성·미추적 상태 이력은 지시장부의 `001 — DOC-02 / A`를 참조한다.
- `DOC-02 / A`: 사용자 확인 완료
- `DOC-02 / B`: 외부 본문 검토 적합 — 문서 이관. 제안과 미정은 승인된 규칙으로 승격하지 않았다.
- `DOC-02 / C`: 외부 본문 검토 적합 — 문서 이관. 제안과 미정은 승인된 규칙으로 승격하지 않았고 실제 플레이·시각·재미를 통과 처리하지 않았다.
- `DOC-02 / D`: 외부 본문 검토 적합 — 문서 이관. 제안과 미정은 승인된 규칙으로 승격하지 않았고 실제 Save/Load·협동 동작을 통과 처리하지 않았다.
- `DOC-02 / E`: 외부 본문 검토 반영 — 문서 이관 보완 2건 적용. 완료 보고 기준 D~E 문서가 `origin/main`에 보존됐다.
- `P0 실행 기반`: 사람 확인 통과. 완료 보고 기준 P0 파일 9개가 `origin/main`에 보존됐다.
- `P1-1 최소 이동`: 사람 확인 통과. 완료 보고 기준 P1-1 파일 11개가 `origin/main`에 보존됐다.
- `P1-2 우클릭 목적지 이동`: 사람 확인 통과 (고정 시험장 우클릭 목적지 이동). 핵심 이동 재확인 뒤 남은 고정 상자 우회·목적지 교체·무효 클릭·근접 목표·F8/F5 재실행도 사용자가 확인했다. P1-2 구현과 높이 보정이 `c42f31e5e2665b39621b11e739bae6022e1094e6`으로 원격 보존됐다는 직전 완료 보고를 이어 기록하며, 이번 새 확인 기록 자체는 아직 원격 미보존이다.
- `P1-3 기본 추적 카메라`: `P1-3 — 핵심 추적·클릭 사용자 확인 완료`. 사용자는 부드러운 추적과 추적 중 실제 우클릭 위치 정확도를 확인했다. 시작·정지, 이동 중 재지정·취소, 경계·재실행과 최종 체감 전체를 통과 처리하지 않는다.
- `P1-4 우클릭 목적지 보정`: `P1-4 — 사물·벽 목적지 보정 사용자 확인 완료`. 실제 사물·벽 클릭 이동을 확인했으며 바닥 밖 배경, 모든 윗면·측면, 입력 전환, 근접 목표·재실행 전체를 통과 처리하지 않는다.
- `Blender-3 + Godot-1 바위 반입`: `구현완료·사람확인대기`. B2 바위 한 개를 GLB로 내보내 독립 Godot 시험 장면에 반입했고, import·파싱·일반 Compatibility 렌더와 바닥 접지 수치를 확인했다. 최종 시각 적합성은 통과 처리하지 않는다.
- `M01 해안·전망 프리뷰`: `해안·전망 통합 구현완료·사람확인대기`. 기존 GLB를 재사용하고 Godot 기본 메시·재질 중심으로 단층 산책로, 경계, 움직이는 바다, 원경, E 전망 진입과 E/Esc/WASD 복귀를 연결했다. M01 캐릭터를 축소하고 평상 카메라를 정면축 그대로 높였으며, 전망 진입 시에만 우측 회전 없이 바다를 살짝 내려다보면서 플레이어 윗부분이 화면 중앙 하단에 조금 보이는 구도로 전환한다. 플레이어 반지름과 달랐던 M01 전용 NavMesh 여유 및 목책 수평 충돌을 최소 조정해 벽·바위 클릭 간격을 줄이고 이동·복귀 뒤 클릭을 재확인했다.
- `M02 Green Coast 첫 탐험·귀환 루프`: `사람확인완료·백업승인`. M01/P1을 재사용해 집·숲 채집·유적의 청록색 유물 기념품·북쪽 해안·귀환 지름길·작업대·전시대·저장/이어하기를 한 장면에 연결했다. 사진 기능은 만들지 않았다. 전망은 지정 표식이나 E 상호작용이 아니라 북쪽의 실제 통행 불가 절벽 끝에 붙어 있는 동안만 자동 활성화하며, 끝자락을 벗어나면 평상 시점으로 자동 복귀한다. 다른 경계와 일반 언덕은 발동 범위가 아니다. 사용자가 최종 세 묶음 확인을 완료하고 관련 결과의 백업을 승인했다.
- 현재 조각: `M02 — Green Coast 첫 탐험·귀환 루프`
- 상태: Green Coast 첫 탐험·귀환 루프 사람확인완료·백업승인
- 다음 행동: M02와 실행에 필요한 바위 반입·M01 의존 변경만 선별 원격 보존한 뒤, 승인된 `DOC-STYLE-01` 문서 정리를 진행한다.
- 중단 지점: 새 게임/이어하기, 집→숲 채집→유적 기념품→북쪽 절벽 자동 전망→지름길 귀환→작업대 설치·전시→저장/복구를 연결했다. M02 전용 NavMesh, 실제 카메라 레이 목적지·경계 정지, 상호작용 거리·시야, 중복 방지, 원자적 재료 소비, 자동 전망의 진입 시 옛 목적지 취소·접촉 유지·이탈 자동 복귀·재접촉, 정상·손상 저장과 일반 Compatibility 화면을 기술 확인했다. 실제 OS 키·마우스 조작, 최종 시각·재미, 사용자의 저장 후 재실행은 사람 확인 전 통과 처리하지 않는다.
- 보존 상태: 로컬 HEAD와 `origin/main` 기준점은 작업 시작 시 `4f427e2d41e57825be444c2ba94fda2eb26ab70a`로 같았다. 사용자가 기존 바위 반입·M01 의존 변경과 이번 M02 결과의 선별 백업을 승인했다.

문서 작성만으로 게임 기능을 통과 처리하지 않는다. 커밋·원격 확인 결과는 해당 작업의 최종 보고에 남긴다.

## [제안] 첫 구현 논의를 위한 초안 순서

1. P0 실행 기반: 지정 Godot에서 최소 3D 화면이 뜨고 다시 열리는지 확인한다. 바닥, 조명, 카메라, 임시 물체 수준이다.
2. P1 이동·시각 시험: 최소 이동과 기본 카메라를 만들고, 별도 작은 조각에서 언덕, 바다, Vista를 시험한다.
3. P2 행동·보상: 채집 한 종류 → 획득·보관 → 가구 한 종류 배치·회수로 나눈다.
4. P3 보존: 최소 저장/로드를 확인한 뒤 같은 배치 영역의 집터 두 곳 사이 이전을 검증한다. 외부 배치는 관련 규칙을 닫은 뒤 확인한다.
5. P4 전투·성장: 확정한 전투 초안으로 적 하나와 업그레이드 하나부터 시작하고, 보스와 트로피는 그 뒤에 연결한다.
6. 첫 완결 루프: 탐험 → 위험·보상 → 귀환 → 성장·꾸미기가 이어진 뒤 사람이 판정한다.

각 묶음은 한 세션짜리 조각이 아닐 수 있다. 실제 착수할 때 화면 요소로 나누고 되는 경우와 안 되어야 하는 경우의 확인 목록을 먼저 쓴다. 기계적 성공, 사용성, 시각 만족, 재미는 별도로 평가한다. 이 순서는 구현 승인이 아니며 P0로 자동 진행하지 않는다.
