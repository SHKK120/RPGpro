# 기록함

## 목적

예전 지시서, 작업 결과, 실제 통과 근거를 보관하는 곳이다.

## 사용 원칙

- 기록함은 현재 정본이 아니다. 오래된 지시를 자동으로 다시 실행하지 않는다.
- 보관 분류의 예는 `지시서`, `작업결과`, `통과샷`이다. 실제 내용이 생길 때 하위 폴더를 추가한다.
- 통과샷에는 실제 플레이 확인 자료만 둔다. 이미지나 플레이 결과를 만들어내지 않는다.
- 큰 영상과 제작 원본은 승인된 외부 보관소에 두고 식별 정보만 연결한다. 현재 작업에서는 업로드하지 않는다.
- 필요한 기록만 읽으며, 보관된 지시서가 후속 단계를 자동 승인하지 않는다.
