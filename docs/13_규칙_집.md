# 집 규칙

## 문서의 역할

집, 가구 배치, 이사와 관련된 플레이 규칙을 정의한다.

## 이 문서가 소유하는 정보

- 집의 기능과 역할
- 가구를 사용하는 공통 규칙
- 이사에 관한 규칙

## 이 문서가 소유하지 않는 정보

- 가구 테마별 콘텐츠 목록
- 아이템 데이터 값
- 집 시스템 구현 코드

## [요구·채택 방향]

- 집터를 기반으로 꾸민 집을 통째로 이사한다.
- 집은 부활, 보관, 제작, 휴식, 성취 전시, 원정의 거점 역할을 한다.
- 내부뿐 아니라 외관과 외부 장식에서도 테마를 표현한다.
- 이사할 때 이미 꾸민 것과 보관한 것을 잃지 않는 경험을 목표로 한다.

## [제안]

- 내부 배치와 집 외관·마당 배치를 분리하여 관리한다.
- 외관은 고정 골격과 교체 부품·재질을 조합한다.
- 집터는 능력치 보너스보다 풍경, 거리, 접근성으로 구분한다.
- 테마를 얻은 지역과 쓰는 지역을 강제로 결합하지 않는다.

## [미정] 이번 검토에서 추가한 질문

- 마당 가구와 외부 장식은 어느 범위까지 함께 이전하는가?
- 집터의 크기, 회전, 경사, 출입구가 다르면 기존 배치를 어떻게 보존하는가?
- 공간이 모자라면 이사를 거절할지, 물품을 보관할지 결정해야 한다. 자동 삭제는 해결책으로 채택하지 않는다.
- 집 안을 같은 3D 월드에 둘지 별도 공간으로 둘지 결정해야 한다.
- 이사 중 저장/로드, 사망, 향후 다른 플레이어의 위치를 어떻게 처리하는가?

두 집터의 배치 가능 영역을 동일하게 만드는 방안은 추천 시험안일 뿐이며 아직 규칙으로 확정하지 않는다.
