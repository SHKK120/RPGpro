# 게임 정체성

## 문서의 역할

게임의 정체성과 전체 방향을 정의한다.

## 이 문서가 소유하는 정보

- 게임의 핵심 정체성
- 플레이어에게 주려는 경험
- 방향을 판단하는 상위 원칙

## 이 문서가 소유하지 않는 정보

- 세부 시스템 규칙
- 콘텐츠 목록과 수치
- 구현 방법

## [요구·채택 방향]

- 빠르게 작은 초본을 완성하고, 이후 콘텐츠를 계속 추가한다.
- 성장, 희귀 아이템, 보스 등의 목표를 이루는 성취와 창작·꾸미기, 위험 뒤의 여유를 중요하게 여긴다.
- 경제 운영은 핵심 재미가 아니다.
- 만들고 싶은 경험과 완성의 성취를 중시하며, 시장성이나 난이도만으로 핵심 취향을 삭제하지 않는다. 현재 작업 크기는 작게 유지한다.
- 장기적으로 친구와의 협동과 소속감을 원한다. 싱글 초본에 길드나 PvP를 바로 넣는다는 뜻은 아니다.
- Godot 4 기반 3D 방향이다. 2D 임시판을 만든 뒤 자동 변환하는 계획이 아니다.

## [제안] 정체성 한 문장

> 위험한 세계에서 얻은 성장을, 내가 고른 풍경 속 나의 집에 남기는 탐험 RPG.

이 문구는 제안이며 제목이나 마케팅 문구로 확정하지 않는다.

## [제안] 사람 판정 질문

1. 원정에서 이루고 싶은 다음 목표가 생기는가?
2. 돌아와 쉬고, 얻은 것을 정리하거나 전시하고 싶은가?
3. 풍경을 본 뒤 저곳으로 가거나 그곳에서 살고 싶은가?
4. 직접 꾸민 결과가 내 성취처럼 느껴지는가?

숫자 합격 기준은 만들지 않는다. 질문을 잴 수단이 갖춰진 뒤 사람이 실제로 판정한다.

## [미정]

- 정식 게임명. `RPGpro`는 작업 폴더명이며 게임 제목으로 확정하지 않는다.
