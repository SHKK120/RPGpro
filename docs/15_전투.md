# 전투

## 문서의 역할

전투의 목적과 플레이 규칙을 정의한다.

## 이 문서가 소유하는 정보

- 전투의 기본 흐름
- 전투 행동과 판정 원칙
- 전투 시작과 종료 규칙

## 이 문서가 소유하지 않는 정보

- 개별 장비와 아이템 수치
- 적 콘텐츠 목록
- 전투 구현 코드

## [요구·채택 방향]

장비, 목표, 보스가 주는 성장과 성취가 핵심 루프에 있다.

## [미정]

- 이동과 조준 입력
- 기본 공격, 회피, 방어, 특수기
- 레벨의 역할
- 장비와 조작 실력의 비중

Souls-like, Diablo-like, Terraria-like 중 어느 하나를 선택한 것으로 기록하지 않는다. 레벨 1~10, 무기 세 종류, 공격·회피 키 등은 과거 예시이며 확정 수치나 구현 명령이 아니다.

전투를 모두 결정하기 전에도 비전투 카메라와 이동 시험은 진행할 수 있다.

## [M03 시험 선택]

M02 Green Coast 안에서 전투가 탐험·귀환·성장과 어울리는지 보기 위해 다음 한정 규칙을 시험한다.

- 좌클릭 근접 공격, Space 짧은 회피, HP 100과 무손실 거점 리스폰
- Prototype Blade 피해 16, Monster Core 4개로 한 번 강화한 뒤 피해 24
- 예고가 있는 근접 적, 비유도 투사체를 쓰는 원거리 적, 강화 차이를 볼 근접 엘리트
- 적 처치 → Core 획득 → 거점 회복·강화 → Ruin Guard 처치 → 저장·계속하기

공격·회피 키, 수치, 적 이름, 강화 비용과 사망 무손실은 M03 플레이테스트용이다. Q-013 전투 기본 규칙과 최종 사망·성장 규칙을 확정하지 않는다. 실제 동작과 사람 확인 범위는 `M03_첫전투성장루프.md`가 기록한다.

## [M04 시험 선택]

- `Tidebound Guardian` 한 체는 기존 Health·Damage·Projectile을 재사용하는 2단계 보스 시험이다.
- HP 약 300, 정면 Sweep 20, 경고 원형 Slam 24, Phase 2의 비유도 3발 Tide Burst 각 10을 사용한다.
- 접촉 피해는 없고 공격 예고와 회복 틈을 둔다. 최근 공격을 즉시 반복하지 않으며 Arena 안에서만 이동한다.
- 플레이어 사망 시 공격·투사체·HUD를 정리하고 Boss HP 300·Phase 1로 되돌린 뒤 기존 M03 거점 리스폰을 사용한다.

이름, 수치, 패턴, Phase와 Arena 잠금은 첫 보스의 가독성과 회피 의미를 확인하는 M04 한정 값이다. 최종 보스 규칙이나 범용 보스 프레임워크로 확정하지 않는다.
