# 전투

## 문서의 역할

전투의 목적과 플레이 규칙을 정의한다.

## 이 문서가 소유하는 정보

- 전투의 기본 흐름
- 전투 행동과 판정 원칙
- 전투 시작과 종료 규칙

## 이 문서가 소유하지 않는 정보

- 개별 장비와 아이템 수치
- 적 콘텐츠 목록
- 전투 구현 코드

## [요구·채택 방향]

장비, 목표, 보스가 주는 성장과 성취가 핵심 루프에 있다.

## [미정]

- 이동과 조준 입력
- 기본 공격, 회피, 방어, 특수기
- 레벨의 역할
- 장비와 조작 실력의 비중

Souls-like, Diablo-like, Terraria-like 중 어느 하나를 선택한 것으로 기록하지 않는다. 레벨 1~10, 무기 세 종류, 공격·회피 키 등은 과거 예시이며 확정 수치나 구현 명령이 아니다.

전투를 모두 결정하기 전에도 비전투 카메라와 이동 시험은 진행할 수 있다.
