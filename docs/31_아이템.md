# 아이템

## 문서의 역할

아이템 데이터의 분류와 의미를 정의한다.

## 이 문서가 소유하는 정보

- 아이템 분류 체계
- 아이템이 가질 수 있는 속성
- 개별 아이템 콘텐츠 정의

## 이 문서가 소유하지 않는 정보

- 전투의 공통 규칙
- 집과 가구의 공통 규칙
- 아이템 시스템 구현 코드

## [요구·채택 방향]

장비, 도구, 채집 재료, 가구·장식, 수집품, 트로피 등을 게임 플레이에 연결한다.

## [제안]

- 기본 자원의 예로 나무, 돌, 광석을 고려한다.
- 지역 재료를 가구 테마와 연결할 수 있다.
- 같은 행동을 하는 아이템은 데이터를 재사용하고, 새로운 행동은 별도 구현이 필요할 수 있다.
- 모든 무기와 보스를 데이터만 추가하면 완성할 수 있다고 보장하지 않는다.

## [미정]

- 개별 재료
- 드랍률과 필요량
- 도구 단계
