# 나중에

## 문서의 역할

현재 조각의 범위 밖에 있는 후순위 아이디어를 보관한다.

## 이 문서가 소유하는 정보

- 나중에 검토할 기능과 콘텐츠 아이디어
- 현재 구현하지 않는 확장 가능성
- 보류 이유

## 이 문서가 소유하지 않는 정보

- 현재 조각의 작업
- 확정된 게임 규칙
- 구현 전에 즉시 닫아야 하는 결정

아래 항목은 아이디어 보관이며 구현 명세나 제작 의무가 아니다.

| 이름 | 지금 미루는 이유 | 다시 여는 조건 |
|---|---|---|
| 실제 Steam 협동 구현 | 싱글플레이 초본과 협동 구조 경계를 먼저 검증한다. | 싱글 핵심 루프와 저장 경계가 확인되고 협동 조각을 별도로 승인할 때 |
| 플레이어 Creative/Creator | 일반 플레이 규칙 및 개발자 진단과 권한 목적이 다르다. | 기본 건축·아이템·저장 규칙과 치트 격리 방식을 정한 뒤 별도 승인할 때 |
| 논리장치·커맨드 | 현재 핵심 루프에 필요하지 않고 별도 시스템 범위가 크다. | 기본 집 꾸미기와 상호작용이 완성된 뒤 자동화 수요가 확인될 때 |
| 완전 자유 건축 | 집터 기반 집·가구 초본보다 충돌·저장·이전 범위가 크다. | 집터 기반 배치와 이사 보존을 먼저 검증한 뒤 별도 승인할 때 |
| 농사 확대 | 핵심 탐험·귀환 루프의 초기 완성보다 후순위다. | 기본 채집과 집 거점 루프가 완성되고 농사 역할을 정할 때 |
| 낚시 | 독립적인 조작·보상·콘텐츠가 필요하다. | 기본 채집과 지역 보상 구조를 확인한 뒤 별도 조각으로 승인할 때 |
| 펫 | 행동, 성장, 저장, 협동 경계가 추가된다. | 플레이어·월드 상태와 저장 구조가 검증된 뒤 역할을 정할 때 |
| 탈것 | 이동·카메라·월드 크기와 충돌 규칙에 영향을 준다. | 기본 이동과 지역 규모를 확인한 뒤 필요성이 생길 때 |
| 배 | 물·해안·이동·카메라·저장 범위가 함께 늘어난다. | 해안 지역과 기본 이동이 검증되고 항해 목적을 정할 때 |
| NPC 마을 | 대화, 상태, 콘텐츠 제작 범위가 크다. | 첫 지역과 핵심 루프가 완결된 뒤 마을의 역할을 정할 때 |
| 길드 | 싱글 초본과 친구 초대형 협동보다 큰 사회 시스템이다. | 실제 협동을 검증하고 지속 조직의 필요성이 확인될 때 |
| PvP | 현재 협동·성취 중심 방향과 별도 밸런스·권한이 필요하다. | 협동 이후에도 명확한 목적과 별도 승인이 생길 때 |
| 대규모 자동화 | 초기 콘텐츠와 구조가 안정되기 전에는 범용화 비용이 크다. | 반복 제작 부담과 자동화 대상이 실제로 확인될 때 |
| 복잡한 스킬트리 | 전투·성장 기본 규칙이 아직 미정이다. | P4의 작은 성장 루프를 검증한 뒤 확장 필요성이 확인될 때 |

현재 필요한 멀티플레이 구조 경계는 후순위로 밀지 않으며 `35_멀티경계.md`가 소유한다. 개발자 진단은 필요한 버그 조각에서만 범위를 정해 사용하고, 플레이어용 Creative/Creator와 같은 항목으로 취급하지 않는다.
