# M02 — Green Coast 첫 탐험·귀환 루프

## 상태

`M02 — Green Coast 첫 탐험·귀환 루프 사람확인완료·백업승인`

이 문서는 M02 시험 장면의 범위, 기술 확인 결과와 마지막 사람 확인 항목을 기록한다. 이번 수치와 조작은 시험값이며 정식 콘텐츠·Vista 규칙으로 확정하지 않는다.

## 실행

- 메인 장면: `res://scenes/prototype/green_coast_m02.tscn`
- Godot에서 F6로 위 장면을 실행하거나 F5로 프로젝트를 실행한다.
- 이동: WASD 또는 우클릭
- 가까운 채집물·유적 기념품·작업대·전시대 상호작용: E
- 메뉴: Esc
- 북쪽 절벽 전망: 실제 통행 불가 절벽 끝에 붙어 있는 동안 자동 활성화, 이동해 끝자락을 벗어나면 자동 비활성화

## 구현한 한 바퀴

1. 시작 화면에서 새 게임 또는 이어하기를 선택한다. 기존 진행이 있을 때 새 게임은 한 번 더 확인한다.
2. 집 왼쪽 작은 숲에서 목재와 돌을 모은다. 고정 ID로 획득을 기록해 다시 주울 수 없다.
3. 오른쪽 유적 안으로 들어가 청록색 유물 기념품을 한 번 획득한다. 사진·촬영·사진 기념품 기능은 만들지 않았다.
4. 북쪽 해안으로 가서 통행 불가 절벽 끝에 닿으면 그 위치를 기준으로 카메라가 아래 바다를 자동으로 내려다본다. 끝자락에 붙어 있는 동안 유지되고, WASD 또는 내륙 우클릭 이동으로 벗어나면 평상 시점으로 자동 복귀한다. 지정된 전망 표식이나 E 상호작용은 없다. 서·동·남쪽 경계와 일반 언덕에서는 발동하지 않는다.
5. 중앙 지름길로 집에 돌아와 목재 4·돌 2를 작업대에 한 번 설치하고, 획득한 유물을 전시대에 한 번 전시한다.
6. 메뉴의 저장 후 종료로 진행을 JSON에 보존하고 이어하기로 수집·설치·전시 상태와 위치를 복구한다.

## 장면과 안전 경계

- M01의 플레이어·추적 카메라·우클릭 목적지 처리와 반입한 `b2_rock_01.glb`를 재사용한다.
- 새 숲·유적·집·길·울타리·절벽은 Godot 기본 메시와 재질로 장면 시작 때 한 번 만들며 매 프레임 다시 생성하지 않는다.
- 걸을 수 있는 영역은 높이 0의 단층이다. 아래 해안과 바다는 시각 배경이며 목적지·수영 구간이 아니다.
- 북쪽 바다 쪽 절벽 면이 보이는 실제 통행 불가 경계다. 자동 전망은 `z <= -10.65`, `|x| <= 12.5`인 그 경계에서만 발동하며, 내륙 `z > -9.6` 또는 북쪽 끝의 좌우 범위 밖으로 벗어나면 자동 해제된다.
- 전망에 들어갈 때 이전 자동 이동·대기 클릭·목적지 표식을 취소한다. 전환이 끝나면 이동을 다시 허용하며, 끝자락에 붙어 있으면 전망을 유지하고 벗어나면 정상 추적으로 자동 복귀한다. E는 전망을 토글하지 않고 Esc는 평소와 같이 메뉴를 연다.

## 저장 시험 범위

- 경로: `user://prototypes/green_coast_m02/save_v1.json`
- 이전 정상본: `save_v1.previous.json`
- 저장은 임시 파일을 다시 읽고 검증한 뒤 교체한다. 현재 파일이 정상일 때만 이전본으로 보존한다.
- 버전·지역 ID·플레이어 위치·목재·돌·획득 ID·기념품 보유/전시·작업대 설치를 저장한다.
- 손상 JSON·지원하지 않는 버전·필수 필드 오류는 불러오지 않고 원본을 덮어쓰지 않는다. 저장 위치가 NavMesh에서 벗어나면 아이템·설치 상태는 유지하고 안전한 시작점으로 복귀한다.
- 이 형식과 백업 1개는 M02 시험안이다. 정식 세이브 정책을 확정하지 않는다.

## 기술 확인

- M02 전용 NavMesh: 정점 112, 폴리곤 116. 집→숲 10점, 숲→유적 14점, 유적→해안 12점, 해안→집 지름길 12점 경로가 연결됐다.
- 실제 카메라 레이를 사용한 이동 진단: 빈 바닥 목적지 오차 0.335m. 남쪽 경계의 접점→목적지 간격 0.950m·최종 정지 오차 0.317m, 유적 벽은 0.825m·0.283m였다. 표식과 실제 NavigationAgent 목적지는 같았다.
- 메뉴가 열린 동안 월드 우클릭이 새 목적지로 새지 않았다. 재료 부족은 소모하지 않고, 정확한 재료만 원자적으로 소비하며, 설치·전시·획득을 반복해도 중복 처리하지 않았다.
- 유적 벽이 상호작용 시야를 막고, 북쪽 절벽의 중앙이 아닌 가장자리에서도 자동 전망이 발동했다. 진입 시 옛 목적지를 취소하고, 전망 전환 뒤 이동 가능 상태와 끝자락 이탈 시 자동 복귀·재접촉 시 재진입을 확인했다.
- 저장과 이전 정상본, 이어하기 복구, 손상 JSON 거부를 일회성 진단 경로에서 확인했고 그 시험 저장은 제거했다. 실제 사용자 저장은 실행 전 생성하지 않았다.
- 일반 Compatibility 렌더에서 집·숲·유적·해안·움직이는 바다·원경 바위와 절벽 전망을 확인했다. Intel HD 530의 OpenGL 품질 경고 및 ANGLE 전환은 기존 환경 경고로 남는다.
- OS 수준의 실제 키·마우스 체감, 최종 시각·재미와 사용자의 저장 후 재실행은 기술 확인으로 통과 처리하지 않는다.

## 사람이 한 번에 확인할 것

1. 집에서 숲·유적·북쪽 해안까지 WASD·우클릭으로 이동하고, 북쪽의 실제 못 지나가는 절벽 끝에 붙어 있는 동안만 자동으로 바다를 내려다보는지 확인한다. 내륙으로 벗어나면 평상 시점으로 돌아오며 다른 경계와 언덕에서는 발동하지 않아야 한다.
2. 목재 4개·돌 2개와 청록색 유물을 얻어 집으로 귀환한 뒤, 작업대 설치와 유물 전시를 각각 한 번 하고 중복 소모·중복 획득이 없는지 본다.
3. 저장 후 종료하고 F5로 다시 실행해 이어하기 했을 때 위치·재료·획득물·작업대·전시 상태가 복구되는지 확인한다.
