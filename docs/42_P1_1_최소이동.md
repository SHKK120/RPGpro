# P1-1 최소 이동

## 목표

P0의 고정 시점 시험장을 유지하면서 노란 캡슐을 직접 움직이고 바닥, 고정 상자 두 개, 보이는 외곽 경계와의 기본 충돌을 확인한다.

## 이번 시험 선택

- 조작 대상: 최종 캐릭터가 아닌 노란 캡슐
- 이동: 물리 키 WASD, 카메라의 수평 방향 기준 전후좌우
- 이동 속도: `scripts/prototype/p1_player.gd`의 `move_speed` 기본값 4.0 월드 단위/초
- 감각: 관성·달리기 없이 키를 떼면 수평 이동 정지
- 대각선: 허용하되 월드 방향 길이를 최대 1로 제한
- 카메라: P0와 같은 원근 투영의 높은 사선 고정 시점. 추적·회전·줌 없음
- 충돌: 바닥, 밀리지 않는 상자 두 개, 보이는 낮은 외곽 막이 네 개
- 재실행: 저장이나 부활 없이 씬의 초기 위치에서 시작

WASD와 캡슐은 P1-1 시험용이다. 최종 캐릭터, 최종 조작, 전투 입력, 월드 경계와 추락·사망 규칙을 확정하지 않는다.

## 여는 방법과 입력

1. `C:\godot\godot.exe --editor --path C:\Users\CKIRUser\RPGpro`로 프로젝트를 열거나 프로젝트 관리자에서 가져온다.
2. 프로젝트 실행(F5)으로 `res://scenes/prototype/p1_movement.tscn`을 연다.
3. 실행 화면에 입력 포커스를 둔 뒤 W/A/S/D를 사용한다.
4. 정지(F8) 후 다시 F5를 누르면 초기 위치에서 시작한다.
5. P0 비교가 필요하면 `res://scenes/prototype/p0_bootstrap.tscn`을 열고 현재 씬 실행(F6)을 사용한다.

## 사람 확인 결과

- [사용자 보고/2026-09-06] WASD 이동과 키를 놓았을 때 수평 이동 정지를 확인했다.
- [사용자 보고/2026-09-06] 장애물 안쪽 진행은 막히며, W+A를 유지하면 가능한 입력 방향으로 벽을 따라 부드럽게 이동하는 것을 확인했다. 덜덜 떨거나 튕기는 현상은 보고되지 않았다.
- [사용자 보고/2026-09-06] 외곽 모서리에서 바닥 밖으로 빠지지 않고, 고정 카메라·재실행·P0 비교가 가능함을 확인했다.
- 표시된 OpenGL 3.3 품질 및 ANGLE 전환 메시지는 기존 환경 경고다. 경고가 있는 상태에서 위 조작 확인을 진행했으며 경고가 해결됐다고 판단하지 않는다.
- 이 확인은 P1-1 최소 이동에 한정한다. 대각선 속도를 사람이 수치로 실측하지 않았고, 성능·최종 아트·재미와 최종 캐릭터·입력·카메라 방식은 검증하거나 확정하지 않았다.

## 기술 확인

- Godot `4.7.2.stable.official.ed1daf0bf`에서 headless import, GDScript 파싱과 P1-1 메인 씬 5회 반복 로드: 오류 없이 완료.
- 일반 그래픽 Compatibility 실행: 프레임 표시와 정상 종료 완료. P0 때와 같은 Intel HD Graphics 530의 OpenGL 3.3 품질 경고 및 ANGLE 전환이 있었고 새 스크립트·씬 오류는 없었다.
- `project.godot`의 물리 키 WASD 네 액션과 P1-1 메인 씬 지정: 직접 확인 완료.
- Player의 Camera3D 경로 연결, CharacterBody3D·CapsuleShape3D, 바닥·상자·막이의 StaticBody3D·BoxShape3D 구성: 직접 확인 완료.
- 코드에서 카메라 수평 방향 변환, 대각선 길이 제한, 중력에만 delta 적용, `move_and_slide()` 사용과 입력 없는 수평 속도 정지를 확인했다.
- P0 원본 `p0_bootstrap.tscn`: Git diff 없음과 별도 로드 가능 상태 확인.
- 엔진 생성 소스 보조 파일: `scripts/prototype/p1_player.gd.uid`. `.godot/` 캐시와 구분한다.
- 위 기술 확인과 별도로, 이후 사용자 보고를 통해 실제 WASD 감각, 정지, 상자·외곽 충돌, 고정 카메라, 재실행과 P0 F6 비교를 확인했다.
