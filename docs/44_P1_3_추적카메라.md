# P1-3 추적 카메라

## 목표

검증된 WASD·우클릭 목적지 이동을 유지하면서 기존 높은 사선 카메라가 플레이어의 수평 이동을 부드럽게 따라가는지 작은 P1 시험장에서 확인한다.

## 이번 시험 선택

- 기존 `Camera3D` 하나의 원근 투영, 시작 위치 Y=8, 회전 `(-30, 0, 0)`과 FOV를 유지한다.
- 시작 플레이어와 카메라의 XZ 오프셋을 보존하고 플레이어 XZ만 따라간다. 플레이어 중력이나 접촉에 따른 Y 변화는 따라가지 않는다.
- `_process(delta)`에서 `1-exp(-k*delta)` 지수 감쇠를 사용하며 시험 반응 속도 `k=10.0/초`만 노출한다.
- 정지 뒤 목표 위치와의 오차가 매우 작아지면 정확한 목표 위치로 맞춘다.
- 카메라 회전·줌·가장자리 스크롤·충돌 회피·위치 제한과 새 입력은 추가하지 않는다.
- 움직이는 카메라에서 우클릭 화면 좌표가 다음 물리 프레임의 다른 카메라 자세로 해석되지 않도록 클릭 순간의 월드 레이 원점·방향을 저장한다.
- 수락한 목적지와 표식은 월드 위치를 유지한다. 카메라 추적값을 플레이어 물리·내비게이션 좌표에 사용하지 않는다.

이 값과 방식은 P1-3 시험용이며 최종 카메라·입력·캐릭터·아트 규칙이 아니다. 시험장 바깥 배경이 더 보이는 것은 허용하며 이를 가리기 위한 맵 확장이나 자동 줌은 하지 않는다.

## 사용자 확인

- 이동 중 카메라가 부드럽게 잘 따라오는 것을 확인했다.
- 카메라 추적 중 실제 우클릭 위치가 정확한 것을 확인했다.
- 이 확인은 시작·정지, 이동 중 재지정·취소, 경계·재실행과 성능·최종 체감 전체를 통과했다는 뜻은 아니다.
- 현재 기록 상태: `P1-3 — 핵심 추적·클릭 사용자 확인 완료`.

## 여는 방법

1. Godot에서 `C:\Users\CKIRUser\RPGpro` 프로젝트를 연다.
2. F5로 `res://scenes/prototype/p1_movement.tscn`을 실행한다.
3. WASD와 바닥 우클릭을 각각 사용하고 이동 중 재지정·WASD 취소도 확인한다.
4. F8로 종료한 뒤 F5로 다시 실행해 초기 구도와 연결을 확인한다.

## 사람 확인 목록

| 항목 | 기대 동작 | 안 되어야 할 동작 | 상태 |
|---|---|---|---|
| 시작·정지 | 시작 구도가 유지되고 입력 없으면 가만히 있음 | 원점에서 날아오거나 계속 미세 이동 | 미확인 |
| WASD 추적 | 이동하면 카메라 위치가 따라오고 방향과 줌은 일정 | 플레이어가 화면을 빠져나감, 화면 회전, 큰 튕김·떨림 | 부분 확인 — 이동 중 부드러운 추적; WASD별 세부는 미확인 |
| 우클릭 중 추적 | 바닥 클릭으로 이동하면서 카메라도 따라오고 목표는 바닥 같은 자리에 남음 | 표식이 플레이어와 함께 끌려오거나 목표가 계속 멀어짐 | 사람 확인 — 추적 중 실제 우클릭 위치 정확 |
| 이동 중 재지정·취소 | 추적 중 새 바닥 클릭 위치가 맞고, WASD 개입 시 자동 이동 취소 | 클릭한 곳과 다른 곳으로 이동, 옛 클릭이 되살아남 | 미확인 |
| 정지·경계·재실행 | 상자 우회·외곽 충돌을 유지하고 정지 후 카메라가 안정됨. F8/F5로 같은 초기 구도 | 경계 밖 이동, 카메라가 계속 흔들림, 재실행 후 참조 누락 | 미확인 |

외곽에서 빈 배경이 더 보이는 것만으로 실패 처리하지 않는다. 최종 카메라가 편한지에 대한 의견은 기능 확인과 별도로 남긴다.

## 기술 확인

- Godot `4.7.2.stable.official.ed1daf0bf`에서 프로젝트 import, 새 GDScript 파싱과 메인 씬 짧은 headless 로드: 오류 없이 완료.
- 실제 `p1_movement.tscn` 단발 진단에서 WASD로 플레이어가 수평 2.0 이동한 동안 카메라가 추적했고, 정지 후 기대 오프셋 위치 오차 0으로 수렴했다. 카메라 Y·회전·FOV는 변하지 않았다.
- 실제 플레이어의 자동 이동 중 카메라 위치는 1.566 이동했고 목적지 표식의 월드 위치 변화는 0이었다. Agent의 `path_height_offset=-0.9`도 유지됐다.
- 진단은 실제 씬·노드와 입력 액션 및 기존 목적지 수락 함수를 사용했지만 실제 화면 우클릭은 하지 않았다. 추적 중 클릭 좌표·체감과 위 사람 확인 목록은 사람 확인 대기다.
- 진단용 임시 스크립트는 제거했다. 엔진이 `scripts/prototype/p1_camera_follow.gd.uid`를 생성했다.
