# 지시 장부

## 문서의 역할

사용자 지시로 바뀐 프로젝트 방향과 작업 규율뿐 아니라, 그 지시로 실제 수행한 구현·문서 작업 이력을 관리한다.

## 이 문서가 소유하는 정보

- 사용자 지시의 요약
- 지시가 영향을 주는 문서와 조각
- 기존 결정의 변경 또는 폐기 이력
- 실제 수행한 작업과 확인 결과

## 이 문서가 소유하지 않는 정보

- 게임 디자인의 정본
- 구현 세부 사항
- 추측으로 만든 결정

## 현재 확정된 내용

### 001 — DOC-02 / A

▶ 지시
[요약] `instruction_02_reviewed.md`를 읽고 A만 수행하며 B~E와 게임 코드는 진행하지 말라는 사용자 지시.

자리
`AGENTS.md`, `docs/00_시작.md`, `docs/01_환경복구.md`, `docs/40_구현순서.md`, `docs/지시장부.md`, `docs/기록함/README.md`, `docs/기록함/지시서/instruction_02_reviewed.md`의 기록·복구·재개 절.

한 일
A-1~A-5의 운영 문서를 보완하고 기록함 안내와 지시서 보관본을 만들었다. 검토 에이전트 0.

바뀐 정본
작업 규율은 `AGENTS.md`, 문서 라우팅과 소유 경계는 `00_시작.md`, 확인된 환경과 복구 절차는 `01_환경복구.md`, 현재 조각과 다음 행동은 `40_구현순서.md`, 실제 지시·변경 이력은 이 장부가 소유한다.

반경
변경 파일 7개. A의 운영 문서와 기록 보관 경로만 바꾸며 B~E 주제 문서와 게임 코드에는 영향 없음.

확인법
직접 확인: 작업 경로, Git 저장소·브랜치·remote 이름, `project.godot` 부재, Godot 실행 파일과 버전, 대상 파일 내용. 사람이 볼 것: A의 문서 표현과 다음 단계 승인. 미확인: 렌더러, Codex 정확한 제품명·빌드·선택 방법, 한 세션 가용 시간, 이번 변경의 원격 보존.

### 002 — DOC-02 / B

▶ 지시
[요약] A 보고 확인 후 `instruction_02_reviewed.md`의 B만 수행하고 보고하라는 사용자 지시.

자리
`docs/10_정체성.md`, `docs/11_규칙_핵심루프.md`, `docs/12_규칙_월드탐험.md`, `docs/13_규칙_집.md`에 B의 정체성·루프·월드·집 내용을 이관하고, `docs/40_구현순서.md`와 이 장부의 재개 상태를 갱신했다.

한 일
요구·채택 방향, 제안, 미정을 구분하여 B의 네 주제 문서를 보완했다. C~E 및 게임 코드는 수행하지 않았다. 검토 에이전트 0.

바뀐 정본
게임 정체성은 `10_정체성.md`, 핵심 루프는 `11_규칙_핵심루프.md`, 월드 탐험 방향은 `12_규칙_월드탐험.md`, 집과 이사 규칙은 `13_규칙_집.md`가 소유한다. 현재 단계와 다음 행동은 `40_구현순서.md`가 소유한다.

반경
변경 파일 6개. B의 주제 문서 4개와 운영 상태 2개에 한정되며 A 문서, C~E 문서, 게임 코드에는 영향 없음.

확인법
직접 확인: B 대상 파일의 기존 내용, 상태 구분, 대상 파일 존재, UTF-8 내용과 Git 상태. 사람이 볼 것: 요구·채택 방향의 표현, 제안의 채택 여부, 사람 판정 질문과 B 완료 승인. 미확인: 모든 [제안]과 [미정]의 최종 결정, 실제 플레이 결과, 이번 변경의 원격 보존.

### 003 — DOC-02 / C

▶ 지시
[요약] `instruction_02_reviewed.md`의 C만 수행하고 보고하라는 사용자 지시. 함께 전달된 `backup_AB.md`는 참고 자료로만 확인했다.

자리
`docs/14_아트스타일.md`, `docs/15_전투.md`, `docs/31_아이템.md`, `docs/32_가구테마.md`에 C의 시각·전투·아이템·가구 테마 내용을 이관하고, `docs/40_구현순서.md`와 이 장부의 재개 상태를 갱신했다.

한 일
요구·채택 방향, 제안, 예시, 미정을 구분하여 C의 네 주제 문서를 보완했다. D~E, 게임 코드, 에셋 제작과 외부 도구 연결은 수행하지 않았다. 검토 에이전트 0.

바뀐 정본
시각·카메라·에셋 원칙은 `14_아트스타일.md`, 전투 방향은 `15_전투.md`, 아이템 분류와 후보는 `31_아이템.md`, 가구 테마 방향과 예시는 `32_가구테마.md`가 소유한다. 현재 단계와 다음 행동은 `40_구현순서.md`가 소유한다.

반경
변경 파일 6개. C의 주제 문서 4개와 운영 상태 2개에 한정되며 A~B 문서, D~E 문서, 게임 코드에는 영향 없음. `backup_AB.md`는 수정하거나 저장소에 복사하지 않았다.

확인법
직접 확인: C 대상 파일의 기존 내용, 상태 구분, 대상 파일 존재, UTF-8 내용과 Git 상태. 사람이 볼 것: 시각 방향, 전투 성장 방향, 아이템·테마 제안과 C 완료 승인. 미확인: 실제 시각·플레이 결과, 모든 [제안]과 [미정]의 최종 결정, 에셋 파이프라인의 실제 적용, 이번 변경의 원격 보존.

### 004 — DOC-02 / A~C 문서 중간 보존

▶ 지시
[요약] `approve_AC.md`의 조건에 따라 A~C 문서 백업을 승인한다는 사용자 지시.

자리
`docs/40_구현순서.md`와 이 장부에 B·C 외부 본문 검토 결과와 보존 작업을 기록하고, 승인된 문서 21개만 중간 보존 대상으로 삼았다.

한 일
전달받은 검토 결과에 따라 B와 C를 `외부 본문 검토 적합 — 문서 이관`으로 기록했다. 제안·미정 및 게임 기능의 상태는 바꾸지 않았다. 승인된 21개 문서의 checkpoint 보존 절차를 시작했으며 실제 commit/push 결과와 커밋 ID는 최종 보고에서 확인한다. 검토 에이전트 0.

바뀐 정본
B·C의 문서 이관 검토 상태와 다음 행동은 `40_구현순서.md`가 소유한다. 게임 기획의 제안·미정 정본은 변경하지 않았다.

반경
내용 변경 파일 2개, 보존 승인 범위 21개. `instruction.md`, `docs/기록함/모델 설정.md`, Downloads의 임시 지시서, 게임 파일은 제외한다.

확인법
직접 확인: 저장소 경로, `main` 브랜치, `origin`의 안전한 목적지, 준비 이후 승인 파일 내용 불변, staged 변경 부재, 로컬·원격 시작 커밋 일치. 전달된 외부 검토 결과: B·C 문서 이관 적합. 사람이 볼 것: checkpoint와 다음 D 지시. 실제 commit/push 및 원격 커밋 일치는 최종 보고에서 확인한다.
