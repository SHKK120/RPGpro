# 지시 장부

## 문서의 역할

사용자 지시로 바뀐 프로젝트 방향과 작업 규율뿐 아니라, 그 지시로 실제 수행한 구현·문서 작업 이력을 관리한다.

## 이 문서가 소유하는 정보

- 사용자 지시의 요약
- 지시가 영향을 주는 문서와 조각
- 기존 결정의 변경 또는 폐기 이력
- 실제 수행한 작업과 확인 결과

## 이 문서가 소유하지 않는 정보

- 게임 디자인의 정본
- 구현 세부 사항
- 추측으로 만든 결정
