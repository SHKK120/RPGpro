# PLAYTEST-01 — First Game Skeleton 통합 점검

## 상태

**정적 통합 점검·즉시 보정 완료 / headless 파싱·메인 장면 스모크 통과 / 실제 플레이 미확인**

현재 MACRO-01 로컬 상태를 기준으로 Home → Green Coast → Region 2 → Home → Save/Continue의 코드·씬·상태 연결을 대조했다. 체크포인트 직전 Godot 4.7.2 headless editor import/파싱과 메인 장면 4프레임 스모크 실행은 종료 코드 0으로 통과했다. 실제 그래픽 F5 한 바퀴와 OS 입력 조작은 실행하지 못했으므로 전체 루프와 조작감을 통과 처리하지 않는다.

## 발견하고 바로 수정한 주요 문제

1. 검 Area 감시를 켠 직후 이미 겹친 대상을 이벤트만으로 놓칠 수 있었다. 공격 활성 시간 동안 실제 겹친 Body를 매 프레임 확인하되 대상별 1회 피해 제한을 유지했다.
2. Region 2의 초기 직사각형 NavMesh가 Landmark와 봉인된 Future Boss 구역을 이동 가능으로 포함했다. 세 개의 연결된 이동 구획으로 나눠 막힌 동쪽 북부를 목적지에서 제외했다.
3. 확장 Save가 Region 2 미해금 상태에서 Region 2 위치를 기록하거나, 음수 Storage·잠기지 않은 Coastal 테마 등 모순 상태를 허용했다. 기존 Save의 누락 키 호환은 유지하면서 새 값이 있을 때의 타입·범위·의존 조건을 검증한다.
4. Region 2 Gate가 기존 Home 집 충돌체 안에 배치되어 실제로 접근할 수 없었다. 집 동쪽 이동 가능 영역으로 옮기고 Home에서 이어지는 청록 바닥 안내선을 추가했다.
5. 이동 속도 선택이 없어 넓어진 골격을 이동하기 불편했다. `[PLAYTEST-01 임시 보정]`으로 Shift를 누르는 동안 WASD와 우클릭 이동을 기본 속도의 1.65배로 처리하고 회피 속도는 유지했다.
6. Region 2가 동쪽 먼 곳의 같은 높이 사각 바닥으로 떨어져 있어 이전 지역과 지형 관계를 읽을 수 없었다. 실제 Home 남쪽의 Y=8 고산 대지로 재배치하고, 아래에 기존 Home·평원·숲과 북쪽 바다가 계속 렌더되도록 연속 지형 기초를 추가했다. 고산 경계의 보이는 벽은 숨기고 지표면에서 아래로 8m 떨어지는 암벽 면과 보이지 않는 안전 충돌로 교체했다.
7. 기존 추적 카메라는 월드 Y=9.5에 고정되어 고산 진입 시 플레이어 높이를 따라오지 못했다. 공유 카메라에 기본 비활성인 다층 추적 옵션을 추가하고 MACRO-01에서만 사용했다. 고산 북쪽 끝 자동 전망은 실제 아래쪽 Home 중심을 향한다.

## 코드 흐름에서 확인한 연결

- New Game은 기존 진행을 초기화하고 Home/Green Coast 안전 시작점에 둔다.
- Green Coast 완결 상태가 Region 2와 Coastal 테마를 해금한다.
- 지역 전환은 기존 이동 목적지·공격·투사체를 정리하고 카메라 상대 위치를 유지한다.
- Region 2에는 Ore 4개, 강한 적 1체, Landmark, 자동 Vista, Homestead Site와 귀환 통로가 서로 다른 위치에 있다.
- Home 귀환 뒤 Ore 3개로 고정 Lamp를 만들며 Storage·Theme·제작 결과가 같은 Save에 포함된다.
- 과거 M02~M04 Save는 새 키가 없어도 Green Coast와 빈 Macro 상태를 기본값으로 사용한다.
